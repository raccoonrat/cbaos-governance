# 主张纪律（Claim Discipline）

## 主张分级

| 级别 | 描述 | 对外使用 | 需要证据包 |
|------|------|----------|------------|
| L0 观察 | 单次测试结果、日志片段 | 仅内部 | 否 |
| L1 趋势 | 在窗口内的统计行为 | 谨慎，需脚注范围 | 建议 |
| L2 设计意图 | 架构/代码意图说明 | 可对外，需版本锚定 | 建议 |
| L3 保证 | 合同/SLA/合规口径 | 仅按 `guarantee_grammar.md` | 是 |

## 升格规则

- L0 → L1：需定义采样窗口与统计方法。
- L2 → L3：需项目负责人或指定 Accountable 书面批准，并创建/更新保证条目与证据链。

## PR 中的主张

- 在 PR 描述中声明新保证或强化旧保证时，必须链接 **机制证据包** 或 **发布证据包** 草稿。
- Reviewer 应默认 **拒绝** 未绑定证据的 L3 措辞。

## 降级与撤回

- 当证据不再成立（例如依赖服务降级），保证维护方须在决策日志记录降级或撤回，并更新对外文档。
